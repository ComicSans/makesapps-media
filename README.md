# makesapps-media

Finished, approved short videos of the @makesapps account (Instagram, TikTok), attached as release assets so the scheduler can fetch them by URL.

No code, no drafts. The renderer lives elsewhere.

## Contents

- `screenshots/<app>/<en|de>/<iphone|ipad>/`: App Store screenshots of the version on sale, taken from the live store listing on 2026-09-29 (CLAUDIO 14.1, Sudoku Pro 4.4, Find Picture Pairs 2.1, Quadrivium 1.0; Quadrivium has no iPad set).
- Releases, one per week (`2026-W40`, ...): the videos as posted, one MP4 per post.
