# NonoQuest: Японские кроссворды

_Ретро-нонограммы и логика_

`ru` · tobias.reithmeier.PictoQuest · IOS 3.0

## Promotional text

190 нонограмм ручной сборки в 19 кампаниях, теперь с цветными головоломками, звёздами и большой картиной для каждой главы. Каждая сходится одной логикой.

## Description

NonoQuest соединяет классические картинки-логику с обликом ретро-консоли и лёгкой приключенческой нитью.

Каждая головоломка решается одной логикой — гадать не нужно никогда. Ошибки видны рано, а любой ход можно отменить.

Пройдите 19 тематических кампаний и решите 190 собранных вручную головоломок от 5×5 до 20×20, среди них цветные, где логика работает с несколькими цветами. Десять картинок каждой кампании складываются в одну большую картину главы.

Что вас ждёт:
- 190 нонограмм ручной сборки в 19 кампаниях
- Цветные головоломки, где у каждого числа свой цвет
- Большая мозаичная картина для каждой главы
- До трёх звёзд за головоломку: за решение, за решение без подсказок и за решение без ошибок
- Подсказки, которые объясняют следующий логический шаг, и каталог приёмов с примерами
- Головоломка дня, одна и та же для всех в мире, с серией и значками за месяц
- Бесконечный режим в пяти размерах сетки
- Альбом, в котором остаётся видна каждая решённая картинка
- Пошаговое введение для начала
- Семь ретро-режимов отображения по мотивам классического железа
- Чиптюн-музыка для каждой кампании; звук по умолчанию выключен
- Игра без сети с сохранением прогресса, без рекламы и без отслеживания

Без покупки доступны «Первые шаги», цветная кампания «Коробка красок», обучение, головоломка дня и приёмы. Разовая покупка в приложении открывает все остальные кампании и бесконечный режим, без подписки. Если вы купили NonoQuest до версии 3.0, вы получаете всё без новой покупки.

В игру можно полностью играть с VoiceOver, Switch Control и клавиатурой. Каждая клетка называет своё положение, своё состояние и числа подсказок.

Называйте их нонограммами, японскими кроссвордами или картинками-логикой — NonoQuest делает ставку на понятное управление, приятные раскрытия и выразительную ретро-атмосферу.
