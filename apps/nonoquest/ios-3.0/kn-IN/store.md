# NonoQuest: ನೊನೊಗ್ರಾಮ್ ಒಗಟು

_ರೆಟ್ರೊ ಪಿಕ್ಸೆಲ್ ಲಾಜಿಕ್ ಗೇಮ್_

`kn-IN` · tobias.reithmeier.PictoQuest · IOS 3.0

## Promotional text

19 ಅಭಿಯಾನಗಳಲ್ಲಿ ಕೈಯಿಂದ ರಚಿಸಿದ 190 ನೊನೊಗ್ರಾಮ್, ಈಗ ಬಣ್ಣದ ಒಗಟುಗಳು, ನಕ್ಷತ್ರಗಳು ಮತ್ತು ಪ್ರತಿ ಅಧ್ಯಾಯಕ್ಕೆ ಒಂದು ದೊಡ್ಡ ಚಿತ್ರದೊಂದಿಗೆ. ಪ್ರತಿಯೊಂದೂ ತರ್ಕದಿಂದಲೇ ಬಿಡಿಸುತ್ತದೆ.

## Description

NonoQuest ಶಾಸ್ತ್ರೀಯ ಚಿತ್ರ-ತರ್ಕ ಒಗಟುಗಳನ್ನು ರೆಟ್ರೊ ಹ್ಯಾಂಡ್‌ಹೆಲ್ಡ್‌ನ ನೋಟ ಮತ್ತು ಹಗುರವಾದ ಸಾಹಸ ಕಥೆಯೊಂದಿಗೆ ಬೆಸೆಯುತ್ತದೆ.

ಪ್ರತಿ ಒಗಟನ್ನೂ ತರ್ಕದಿಂದಲೇ ಬಿಡಿಸಬಹುದು — ಊಹಿಸುವ ಅಗತ್ಯ ಎಂದಿಗೂ ಇಲ್ಲ. ತಪ್ಪುಗಳು ಬೇಗ ಕಾಣುತ್ತವೆ ಮತ್ತು ಪ್ರತಿ ನಡೆಯನ್ನೂ ಹಿಂಪಡೆಯಬಹುದು.

19 ವಿಷಯಾಧಾರಿತ ಅಭಿಯಾನಗಳನ್ನು ದಾಟಿ, 5×5 ರಿಂದ 20×20 ರವರೆಗಿನ ಕೈಯಿಂದ ರಚಿಸಿದ 190 ಒಗಟುಗಳನ್ನು ಬಿಡಿಸಿ; ಅವುಗಳಲ್ಲಿ ತರ್ಕವು ಹಲವು ಬಣ್ಣಗಳಲ್ಲಿ ಸಾಗುವ ಬಣ್ಣದ ಒಗಟುಗಳೂ ಇವೆ. ಪ್ರತಿ ಅಭಿಯಾನದ ಹತ್ತು ಚಿತ್ರಗಳು ಸೇರಿ ಒಂದು ದೊಡ್ಡ ಅಧ್ಯಾಯ ಚಿತ್ರವಾಗುತ್ತವೆ.

ನಿಮಗೆ ಸಿಗುವುದು:
- 19 ಅಭಿಯಾನಗಳಲ್ಲಿ ಕೈಯಿಂದ ರಚಿಸಿದ 190 ನೊನೊಗ್ರಾಮ್
- ಪ್ರತಿ ಸಂಖ್ಯೆಗೂ ತನ್ನದೇ ಬಣ್ಣವಿರುವ ಬಣ್ಣದ ಒಗಟುಗಳು
- ಪ್ರತಿ ಅಧ್ಯಾಯಕ್ಕೆ ಒಂದು ದೊಡ್ಡ ಮೊಸಾಯಿಕ್ ಚಿತ್ರ
- ಪ್ರತಿ ಒಗಟಿಗೆ ಗರಿಷ್ಠ ಮೂರು ನಕ್ಷತ್ರಗಳು: ಬಿಡಿಸಿದ್ದಕ್ಕೆ, ಸಹಾಯವಿಲ್ಲದೆ ಮತ್ತು ತಪ್ಪಿಲ್ಲದೆ ಬಿಡಿಸಿದ್ದಕ್ಕೆ
- ಮುಂದಿನ ತಾರ್ಕಿಕ ಹೆಜ್ಜೆಯನ್ನು ವಿವರಿಸುವ ಸುಳಿವುಗಳು ಮತ್ತು ಉದಾಹರಣೆಗಳೊಂದಿಗೆ ತಂತ್ರಗಳ ಪಟ್ಟಿ
- ದಿನದ ಒಗಟು, ಜಗತ್ತಿನೆಲ್ಲೆಡೆ ಎಲ್ಲರಿಗೂ ಒಂದೇ, ಸರಣಿ ಮತ್ತು ತಿಂಗಳ ಬ್ಯಾಡ್ಜ್‌ಗಳೊಂದಿಗೆ
- ಐದು ಜಾಲರಿ ಗಾತ್ರಗಳಲ್ಲಿ ಅಂತ್ಯವಿಲ್ಲದ ಮೋಡ್
- ಬಿಡಿಸಿದ ಪ್ರತಿ ಚಿತ್ರವನ್ನೂ ಕಣ್ಮುಂದೆ ಇಡುವ ಆಲ್ಬಮ್
- ಆರಂಭಕ್ಕೆ ಮಾರ್ಗದರ್ಶಿ ಪರಿಚಯ
- ಶಾಸ್ತ್ರೀಯ ಯಂತ್ರಾಂಶದಿಂದ ಪ್ರೇರಿತ ಏಳು ರೆಟ್ರೊ ಪ್ರದರ್ಶನ ಮೋಡ್‌ಗಳು
- ಪ್ರತಿ ಅಭಿಯಾನಕ್ಕೆ ಚಿಪ್‌ಟ್ಯೂನ್ ಸಂಗೀತ; ಶಬ್ದ ಆರಂಭದಲ್ಲಿ ಆಫ್ ಇರುತ್ತದೆ
- ಪ್ರಗತಿ ಉಳಿಸಿಕೊಂಡು ಆಫ್‌ಲೈನ್ ಆಟ, ಜಾಹೀರಾತಿಲ್ಲ, ಟ್ರ್ಯಾಕಿಂಗ್ ಇಲ್ಲ

ಏನನ್ನೂ ಖರೀದಿಸದೆ ನೀವು “ಮೊದಲ ಹೆಜ್ಜೆಗಳು”, ಬಣ್ಣದ ಅಭಿಯಾನ “ಬಣ್ಣದ ಡಬ್ಬಿ”, ತರಬೇತಿ, ದಿನದ ಒಗಟು ಮತ್ತು ತಂತ್ರಗಳನ್ನು ಆಡಬಹುದು. ಆ್ಯಪ್‌ನೊಳಗಿನ ಒಂದು ಬಾರಿಯ ಖರೀದಿ ಉಳಿದ ಎಲ್ಲ ಅಭಿಯಾನಗಳನ್ನು ಮತ್ತು ಅಂತ್ಯವಿಲ್ಲದ ಮೋಡ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ, ಚಂದಾದಾರಿಕೆ ಇಲ್ಲ. ಆವೃತ್ತಿ 3.0 ಕ್ಕಿಂತ ಮೊದಲು NonoQuest ಖರೀದಿಸಿದ್ದರೆ, ಮತ್ತೆ ಖರೀದಿಸದೆ ನಿಮಗೆ ಎಲ್ಲವೂ ಸಿಗುತ್ತದೆ.

ಆಟವನ್ನು VoiceOver, Switch Control ಮತ್ತು ಕೀಬೋರ್ಡ್‌ನೊಂದಿಗೆ ಸಂಪೂರ್ಣ ಆಡಬಹುದು. ಪ್ರತಿ ಮನೆಯೂ ತನ್ನ ಸ್ಥಾನ, ತನ್ನ ಸ್ಥಿತಿ ಮತ್ತು ತನ್ನ ಸುಳಿವು ಸಂಖ್ಯೆಗಳನ್ನು ಹೇಳುತ್ತದೆ.

ಅವನ್ನು ನೊನೊಗ್ರಾಮ್ ಎನ್ನಿ, ಜಪಾನೀ ಪದಬಂಧ ಎನ್ನಿ ಅಥವಾ ಚಿತ್ರ-ತರ್ಕ ಒಗಟು ಎನ್ನಿ — NonoQuest ಸ್ಪಷ್ಟ ನಿಯಂತ್ರಣ, ತೃಪ್ತಿ ನೀಡುವ ಅನಾವರಣ ಮತ್ತು ವಿಶಿಷ್ಟ ರೆಟ್ರೊ ವಾತಾವರಣವನ್ನು ನೆಚ್ಚಿಕೊಳ್ಳುತ್ತದೆ.
