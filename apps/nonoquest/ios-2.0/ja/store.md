# NonoQuest

_レトロなお絵かきロジック冒険_

`ja` · tobias.reithmeier.PictoQuest · IOS 2.0

## Promotional text

レトロ携帯機の雰囲気で、13の物語キャンペーンにまたがる130問の手作りピクチャーロジックを楽しめます。すべて論理だけで解けます。

## Description

NonoQuest は、クラシックなピクチャーロジックにレトロ携帯機風の演出と軽いアドベンチャー要素を組み合わせた作品です。

すべての問題は論理だけで解けます。当てずっぽうは必要ありません。手が滑ってもすぐに気づけて、どの操作も取り消せます。

13のテーマ別キャンペーンを旅しながら、ドット絵モチーフを解放し、導入向けの小さな盤面から上級者向けの大きな盤面まで、130問の手作りノノグラムを解いていきます。

主な内容:
- 13キャンペーンにわたる手作りのノノグラム130問
- 世界中で同じ内容の「今日の1問」
- 5つの盤面サイズで遊べるエンドレスモード
- 解いた絵がすべて残るアルバム
- 初心者向けのガイド付きチュートリアル
- 答えではなく解き方を教える4段階のヒント
- 往年のハードを思わせる7つのレトロ表示モード
- 広告なし、アプリ内課金なし。進行状況の保存に対応したオフラインプレイ

VoiceOver、スイッチコントロール、キーボードだけで最後まで遊べます。盤面のマスはそれぞれ位置・状態・ヒントの数字を読み上げます。

ノノグラム、ピクロス、ピクチャーロジックのどの名前で呼んでも、NonoQuest では遊びやすい操作感、気持ちのよい完成演出、そして個性的なレトロ空気感を楽しめます。
