# Tsugi: Zen Dominosa Puzzle

_โดมิโนซาที่ซ่อมด้วยทอง_

`th` · tobias.reithmeier.tsugi · IOS 2.0

## Promotional text

โดมิโนซาที่มีคำตอบเดียว คำใบ้ไม่จำกัด ไม่มีนาฬิกาจับเวลา จ่ายครั้งเดียว — ไม่มีโฆษณา ไม่มีสมาชิกรายเดือน ไม่ต้องมีบัญชี

## Description

ตารางตัวเลขซ่อนโดมิโนทุกตัวไว้ตัวละหนึ่งครั้งพอดี สิ่งที่เหลือคือหาว่าแต่ละตัวอยู่ตรงไหน

Tsugi คือโดมิโนซา เงียบ แม่นยำ และแก้ได้ด้วยการให้เหตุผลล้วน ๆ ทุกกระดานมีคำตอบเดียว และไม่มีจุดใดที่ต้องเดา

เก้าระดับ จากเมล็ดสู่ต้นโอ๊ก
แต่ละระดับเพิ่มตัวเลขหนึ่งตัว และเพิ่มคู่ที่ไม่เคยมีมาก่อน เมล็ด หน่อ ต้นกล้า ไปจนถึงต้นโอ๊ก

สามวิธีเล่น
• เรื่องราว — เก้าระดับตามลำดับ
• ไม่จำกัด — ระดับใดก็ได้ เมื่อใดก็ได้
• ความท้าทายประจำวัน — ปริศนาใหม่ทุกวัน

คำใบ้ไม่มีขีดจำกัด
คำใบ้จะเผยตำแหน่งที่ถูกต้องหนึ่งตำแหน่ง บ่อยเท่าที่ต้องการ การติดขัดไม่เคยเป็นจุดจบของเกม

ซ่อมด้วยทอง
ชื่อนี้มาจากคินสึงิ วิธีซ่อมเครื่องปั้นดินเผาที่แตกด้วยทองของญี่ปุ่น กระดานที่แก้สำเร็จจะปิดรอยต่อด้วยทอง ตำหนิกลายเป็นลวดลาย

เงียบโดยการออกแบบ
ไม่มีนาฬิกา ไม่มีคะแนน ไม่มีสถิติต่อเนื่องให้รักษา เพียงตัวถัดไป

เป็นธรรมโดยการออกแบบ
จ่ายครั้งเดียว ไม่มีโฆษณา ไม่มีการซื้อในแอป ไม่ต้องมีบัญชี ไม่มีการติดตาม ไม่มีการส่งข้อมูลออกไป ความคืบหน้าอยู่บนเครื่องเท่านั้น

ในภาษาของคุณ
Tsugi พูดได้ 44 ภาษา ทั้งแอป — กระดาน ระดับ การตั้งค่า

บนทั้งสองจอ
ลงตัวบน iPad ด้วย กระดานที่ใหญ่ขึ้น สร้างมาเพื่อจอที่ใหญ่ขึ้น

VoiceOver อ่านทุกช่องพร้อมแถว คอลัมน์ และค่า ทุกปุ่มมีคำอธิบาย และภาพเคลื่อนไหวเป็นไปตามการตั้งค่าลดการเคลื่อนไหว
