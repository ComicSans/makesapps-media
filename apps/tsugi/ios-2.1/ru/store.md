# Tsugi: Zen Dominosa Puzzle

_Доминоза, сшитая золотом_

`ru` · tobias.reithmeier.tsugi · IOS 2.1

## Promotional text

Доминоза с единственным решением, неограниченными подсказками и без таймера. Одна покупка — без рекламы, без подписки, без аккаунта.

## Description

Сетка чисел прячет каждую костяшку домино ровно один раз. Остаётся найти место для каждой.

Tsugi — это доминоза: тихая, точная, решаемая одним рассуждением. У каждого поля единственное решение, и ничто в нём не угадывается.

ДЕВЯТЬ УРОВНЕЙ, ОТ СЕМЕНИ ДО ДУБА
Каждый уровень добавляет одно число — а вместе с ним пары, которых раньше не было. Семя, Росток, Саженец, вплоть до Дуба.

ТРИ СПОСОБА ИГРАТЬ
• История — девять уровней по порядку
• Без ограничений — любой уровень в любое время
• Ежедневный вызов — новая головоломка каждый день

ПОДСКАЗКИ БЕЗ ПРЕДЕЛА
Подсказка открывает одну верную постановку, столько раз, сколько нужно. Тупик никогда не заканчивает партию.

СШИТАЯ ЗОЛОТОМ
Название происходит от кинцуги — японской починки разбитой керамики золотом. Решённое поле запечатывает свои швы золотом: изъян становится украшением.

ТИХАЯ ПО ЗАМЫСЛУ
Ни таймера. Ни очков. Ни серии, которую надо защищать. Только следующая костяшка.

ЧЕСТНАЯ ПО ЗАМЫСЛУ
Одна покупка. Без рекламы, без встроенных покупок, без аккаунта, без слежки. Ничего никуда не отправляется — прогресс остаётся на устройстве.

НА СВОЁМ ЯЗЫКЕ
Tsugi говорит на 44 языках. Всё приложение — поле, уровни, настройки.

НА ОБОИХ ЭКРАНАХ
Оно подходит и для iPad: поле больше, собрано под большой экран.

VoiceOver читает каждую клетку со строкой, столбцом и значением, у каждого элемента есть подпись, а анимации учитывают «Уменьшение движения».
