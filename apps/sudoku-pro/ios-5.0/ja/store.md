# 数独Pro：パズルとトレーニング

_遊んで、うまくなる。広告なし_

`ja` · tobias.reithmeier.minisudoku · IOS 5.0

## Promotional text

本格数独を遊びながら学べる。練習パズル付きの20の技法。Killer、Samurai、11種類のテーマ、ライトとダーク、ヒントや補助は好みで。買い切りで、サブスクも広告もありません。

## Description

数独Proは、じっくり遊べる本格的な数独であり、数独を学べるトレーニングでもあります。最初の一つの数字から、ソードフィッシュやエックスワイチェーンといった上級・エキスパートの技法まで。

学習パスが20の技法へと導き、どの技法にも専用の練習パズルがあります。ヒントは答えを明かすのではなく、考え方を説明します。ただ遊びたいだけなら、一度も使わなくてかまいません。

遊ぶための要素もすべて揃っています。4x4、6x6、9x9を4段階の難易度で、さらにキラー、iPadではサムライ、今日の一問、メモ、連続記録、統計。盤面は毎回その場で生成され、解は必ず一つ、当て推量なしで解けます。

数独を一歩ずつ学ぶ：
* 学習パス：4段階・20の技法を、ネイキッドシングルからエックスワイチェーンまで。「遊び方」では各技法の例と、自分の進み具合（新規、遭遇済み、練習中、習得済み）が分かります。
* 技法ごとの練習パズル：その技法を使わなければ、より難しい技法でしか先に進めない盤面です。補助なし・ミスなしで3問解けば習得済みになります。
* 上級とエキスパートの技法：Skyscraper、2-String Kite、W-Wing、XYZ-Wing、Unique Rectangle、Simple Coloring、Finned X-Wingなど。
* 2段階のヒント：まず「行3に注目」のような手がかり、望めば次に技法の名前と、盤面に描かれたパターン。
* トレーニング：教科書の例ではなく、自分の盤面で技法を一手ずつ説明します。
* クリア後のパズルのプロフィール：使われた技法、ヒントが必要だった箇所、次に練習するとよい技法。
* メモをチェック：候補が抜けている場所や、すでに除外されたメモがある場所を示します。
* 自分でミスを見つけたい？ エラーをすぐに表示しない設定もあります。
* 子どもと初心者のための4x4と6x6：子どもと一緒に遊んで論理を見せられるように入れました。

好きなように遊ぶ：
* クラシック：4x4、6x6、9x9の3サイズ、4段階の難易度。上級とエキスパートは、より手ごたえのある難しさになりました。
* キラー：合計付きのケージが、その合計がまだ成り立つかをすぐに示します。
* サムライ（iPadのみ）：重なり合う5つの9x9を、21x21のひとつの枠として解きます。
* デイリーパズル：その日は世界中で同じ問題。連続記録とカレンダー付き。
* メモ、ブロックメモ、自動メモ、フォーカスモード、ヘルパーモード。
* 手作りのテーマが11種類。手描き風の「フェルトペン」も含め、虹色から高コントラストまで。
* 統計、自己最高の連続記録、15の実績。すべて端末内で、サインイン不要。
* 解き筋を共有：解答の様子をタイムラプス動画として書き出せます。
* 好きな時刻の毎日のリマインダー。必要な方だけどうぞ。
* 45言語対応。

iPadでは、新聞版。
iPadには独自の世界があります。一面、暦、専用の書体。引き伸ばしたiPhoneではありません。がらりと変えるなら、手描き風のテーマ「フェルトペン」もあります。ペンモードではキーパッドが畳まれて盤面が広がります。見慣れた姿がよければ、クラシックレイアウトに切り替えられます。

このアプリがある理由：
ひとりで開発をしています。数独は何年も好きなのですが、最近は良いアプリを見つけること自体がパズルのようになっていました。しかも、楽しいほうのパズルではありません。サブスク、トラッキング、点滅するバナー、「宝石を100個集めよう」のポップアップ。私はコーヒーと数独があればいいのです。だから自分で作りました。
* 一度の購入でずっと使えます。サブスクなし、隠れたアプリ内課金なし、広告なし、アカウントなし。仕事をきちんとする道具に、適正な価格を。
* すべては手元の端末に。インターネットは不要です。あなたの盤面も連続記録も統計も、あるべき場所にとどまります。追跡はしません。私が知りたいのはご意見だけです。

アクセシビリティは後付けではなく、最初から組み込んでいます。全体でVoiceOver、盤面のDynamic Type、高コントラストのテーマ、切り替えられる触覚フィードバック、そして数字より模様を速く読む方のためのドット表記。

盤面を制して、論理の純粋な楽しさをもう一度。

よい数独を。
Tobias
